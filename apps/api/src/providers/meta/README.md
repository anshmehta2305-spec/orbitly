# Meta (Facebook & Instagram) Provider Setup Guide

## Meta Developer Portal Configuration
1. Register an app in [Meta for Developers](https://developers.facebook.com/apps/).
2. Select "Business" app type.
3. Add Products:
   - Instagram Graph API
   - Facebook Login for Business
4. Permissions required:
   - `instagram_basic`
   - `instagram_content_publish`
   - `pages_show_list`
   - `pages_read_engagement`
   - `pages_manage_posts`
5. Official Docs:
   - [Instagram Content Publishing](https://developers.facebook.com/docs/instagram-platform/instagram-api-with-instagram-login/content-publishing)
