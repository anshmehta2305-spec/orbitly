# Orbitly - Authorized Third-Party Sub-Processors

*LEGAL NOTICE: REVIEW WITH A LAWYER PRIOR TO COMMERCIAL PUBLICATION.*

To support the delivery of the Orbitly social media publishing and analytics platform, Orbitly engages third-party sub-processors. Each sub-processor undergoes security, confidentiality, and data protection diligence under GDPR Article 28.

---

## Current List of Sub-Processors

| Entity Name | Service Purpose | Data Location | Safeguards / Transfer Mechanism |
| :--- | :--- | :--- | :--- |
| **Amazon Web Services, Inc. (AWS)** | Cloud Infrastructure, Virtual Servers, Object Storage (S3) | USA / EU (Frankfurt) | AWS DPA, Standard Contractual Clauses (SCCs) |
| **Cloudflare, Inc.** | CDN, DDoS Protection, R2 Object Storage | Global Edge / USA | Cloudflare DPA, SCCs |
| **Stripe, Inc.** | Payment Processing, Invoicing, Tax Collection | USA / Global | PCI-DSS Level 1 Service Provider, Stripe DPA |
| **Razorpay Software Pvt. Ltd.** | Payment Processing (India & INR transactions) | India | RBI Compliant, Razorpay DPA |
| **Anthropic, PBC** | AI Copywriting & Hashtag Optimization (Claude API) | USA | Anthropic Commercial Terms, Zero Data Retention for Model Training |
| **OpenAI, LLC** | AI Content Generation & Repurposing (GPT API) | USA | OpenAI Business DPA, Zero Training on API Data |
| **Google Cloud Platform (GCP)** | Gemini AI Studio, OAuth Identity Services | USA / EU | Google Cloud DPA, SCCs |
| **Functional Software, Inc. (Sentry)** | Application Error Tracking & Crash Telemetry | USA | Sentry DPA, Automatic PII Redaction Enabled |
| **Postmark / SendGrid** | Transactional Emails (Magic Links, Password Resets) | USA | SCCs, Strict SPF/DKIM authentication |

---

## Notification of Changes
Orbitly maintains a mechanism allowing customers to subscribe to notifications of new sub-processors at least 30 days prior to authorization.
