# Composer & Scheduling Guide

The Orbitly Composer is built for fast cross-channel publishing with platform-specific fidelity.

## Key Features
- **Channel Toggle Avatars:** Click channel avatars to select or unselect target networks.
- **Per-Channel Tailoring Tabs:** Write your baseline message in the **Global** tab, then click individual platform tabs (e.g. X or LinkedIn) to customize character limits, hashtags, and mentions.
- **Thread & Carousel Builders:** Add numbered thread tweets for X/Bluesky or multi-image swipe carousels for Instagram/LinkedIn.
- **First-Comment Automation:** Automatically post links or hashtags in the first comment immediately after publishing.
- **Best Time to Post AI Engine:** Click the sparkle icon next to the date picker to automatically select optimal posting windows based on historical audience engagement.
- **Recurring Queue Slots:** Add posts to predefined category slots (e.g., "Mondays at 10:00 AM") rather than picking manual dates.
